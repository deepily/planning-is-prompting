## 0. Method

Every row below was derived from **source** — `workflow/scripts/memento_record_guard.py`,
`workflow/scripts/memento_io.py`, `~/.claude/settings.json` — not from the two plans. The plan is a
claim; the file is the fact.

Baseline probes were **executed** before any diff existed: the guard driven as a real subprocess with
real JSON on stdin, in a throwaway `git init` repo (`scratchpad/gbase/`), asserting real exit codes.

### Three method rules this review produced, each after it had already cost something

1. **A citation belongs to a commit.** A `file:line` reference is a claim about a *file state*, not a
   file, and it decays the instant the file is edited. **A stale anchor reads exactly like a live
   one**, so care does not catch it — re-derive every citation against the sha under review. (Earned
   by filing F-2 correctly once and re-asserting it wrongly twice; §6.)
2. **When you name a defect class, run it against whatever you are holding at that moment.** Not
   "audit your instrument" — that describes a virtue. This fires on an event: the moment you have
   articulated a class for someone else, check the thing in your own hands. Every self-catch in this
   review arrived that way — the 188→200 census over-statement, the stale anchor, and a
   **count-only assertion in the reviewer's own harness** that was hiding a second defect instance.
   The trigger is **naming the class out loud, whoever it was aimed at**.
3. **A partially-confirmed assertion reads as confirmed.** When an arm asserts two things and one
   passes, the passing half is the one attention lands on. Assert the **exact set** and the **exit
   code**, never the count; *printing* the names of the tests a mutation killed does not answer
   *"are they the right ones."*

### The three rules, priced — every instance below was the recorder's own

A rule with a self-inflicted receipt outranks one with a borrowed example, so the cost is recorded
next to the rule. **All four instances are mine, all four landed on 2026-07-21, and not one was
caught by re-reading — each was caught by an instrument.**

## 2. Findings that landed before the diff

### P1-a — path traversal evades the record predicate
`memento_record_guard.py:66-67`. Input: `Write` to `<repo>/io/mementos/../mementos/rio-abcd1234.md`
where that record **exists** → **exit 0, allowed**. Reproduced. The path segment preceding
`mementos/` is `..`, not `io`, so `RECORD_IO_RE` misses and the immutability guard is bypassed by a
string, not a trick.

Today it defeats F1's own predicate. Under F5 it is worse: the canonical-slot check compares the
`io/mementos` segment against the git toplevel, so **normalization becomes load-bearing**.

**Demand**: `os.path.normpath` + `realpath` before **any** match or compare.
Doctrine: REPOS on `git --git-common-dir`, TREES on `realpath`.
**Disposition**: accepted as specified (Mr. Radio, 12:22).

### P1-b — the guard ignores `payload["cwd"]`
`memento_record_guard.py:135` reads **only** `tool_input.file_path`. The PreToolUse payload does carry
`cwd` (confirmed at `lupin/src/lupin_cli/claude_code/hooks/stop.py:2118`).

`af0c5700` — the bug F5 exists to catch — was a **relative** doctrine-path write
(`io/mementos/<slug>.md` from a session whose cwd was a subdirectory). Reproduced: a relative path's
verdict is entirely a function of the **hook process's** cwd, which is not the agent's. An F5 that
runs `git rev-parse` from `os.getcwd()` resolves the wrong repo and **false-allows the exact bug it
was written to catch** — while passing all seventeen ACs, because every AC in 01b uses an absolute path.

**Demand**: resolve relative targets against `payload["cwd"]`, explicitly, and make the
relative-path arm the **default** test case rather than the exception.
**Disposition**: accepted; Mr. Radio is rewriting ACs 9–16 so relative + explicit `cwd` is the default arm.

### P2 — the record predicate misfires on date-suffixed names

Not currently on disk — but the naming actually in use is date-suffixed

### P1-d — the `rescued-` exemption's justification is REFUTED (executed)

**Claim under review** (Mr. Radio's ruling, 12:22): F1 exempts the `rescued-` prefix from create-denial
because *"rescue artifacts are hand-written; the rescuer has no session to run `write` as."*

**Executed refutation**, throwaway repo, `HOME` monkeypatched:

```
printf '# Rescued memento\n\nbody…\n' | memento_io.py write \
    --persona "rescued maria" --session-id 35446389 --slot io
→ EXIT 0
RECORD   io/mementos/rescued-maria-35446389.md
MIRROR   ~/.claude/mementos/r/io/mementos/rescued-maria-35446389.md
POINTER  io/mementos/rescued-maria.md -> current: io/mementos/rescued-maria-35446389.md
sha256   7f90b94f…  (record == mirror)
```

`--session-id` is a **flag**, not derived from the live session, and `slugify()` turns `"rescued maria"`
into exactly the `rescued-maria-<sid>` the convention wants. **The sanctioned path already handles
rescues, today, with mirror + pointer + sha parity.** The exemption is not required.

**It also re-opens the class F1 exists to close.** Mini Plan 01 §1 says the CREATE hole is unrecoverable
*precisely because* a raw `Write` produces **no mirror and no pointer** — a silent orphan. Exempting
`rescued-` does not grant a convenience; it grants orphans. And `95b2ed7f` (María's rescue of **33
files**) is queued to run through it — 33 orphans by design, the largest single batch of unmirrored
records the fleet would have produced, through the one door F1 was built to shut. **An exemption that
carries the bulk path is not narrow.**

**Recommendation**: kill the exemption rather than pin it. Run `95b2ed7f`'s 33 through
`memento_io.py write` one call per file; each lands record+mirror+pointer+sha, and F1 stays absolute
with no prefix carve-out for a future author to widen. If the post-game gate over-fires on a rescue
batch, `--no-post-game "<reason>"` (`memento_io.py:19`) is the documented escape and **stamps the
reason into the record** — strictly better provenance than a silent raw `Write`.

**If the exemption is kept over this objection**, D7 needs a third condition: a `rescued-` file landed
via the exemption must be proven to have **no mirror and no pointer**, so the test states the actual
consequence instead of letting "allowed" read as "handled." **Status: OPEN, escalated to Mr. Radio.**

### P2 — F5's pointer-side predicate must be broad, or it mostly never runs

### §5.1 — The date-collision escape list, corrected by execution

The 12:28 amendment held that F1's date-collision refusal *"had no satisfiable alternative, because
`write` cannot produce a date-suffixed name"*, and put **dotted-date** on the escape list. Executed
against source, both halves come out otherwise:

| Probe | Result |
|---|---|
| `write --persona "arnold" --session-id 20260721 --slot io` | **EXIT 0** — lands `io/mementos/arnold-20260721.md` + pointer. `short_sid()` accepts it because **`20260721` is valid hex.** |
| `slugify("arnold legacy 2026.07.19")` | → `arnold-legacy-2026-07-19` — dots ARE eaten, so `write` genuinely cannot emit a dotted name |
| `is_record_path("io/mementos/arnold-legacy-2026.07.19-220000.md")` | **pointer** — F1 **never fires on it** |

⇒ **The refusal does have a satisfiable alternative, and it is exact**: pass the eight digits as
`--session-id`; `write` emits the identical filename. And the dotted form is **not an escape from
anything**, because it is pointer-shaped and F1 never blocks it — listing it would document a remedy
for a refusal that does not occur, and imply a block that does not exist.

**Corrected escape enumeration for F1's denial**:
1. `write --persona <p> --session-id <the 8 digits>` — produces the identical name. *(primary; executed)*

### The refutation

The hypothesis under test (Mr. Radio): *a toolchain producing 12% of its own corpus has a
sanctioned path that does not fit what people need to write — a **missing verb**.*

**Refuted.** 72% of the corpus is self-state-at-a-moment, which is **precisely `write`'s artifact

**wearing different names**.

### The bind — and why it is F-1's family

`write` exposes four fields: `--repo`, `--slot`, `--persona`, `--session-id`. **There is no
`--label`**, so the filename is forced to `<persona>-<sid8>.md` — an 8-hex string a future reader
must look up. What people actually reach for is descriptive:

```
arnold-resume-2026.06.17-dm-cutover-quiesce.md
clayton-reap-tombstone-review-resume-2026.06.15.md
extra1-reviewer-resume-2026.06.18.md
```

The obvious workaround — folding the label into `--persona` — **silently forks the pointer**,
because persona determines `pointer_rel_path`. Measured:

```
write --persona "arnold"          --session-id 11111111   → pointer arnold.md → arnold-11111111.md
write --persona "arnold reviewer" --session-id 22222222   → pointer arnold-reviewer.md   EXIT 0, no warning
resolve --persona "arnold"                                → arnold-11111111.md   ← THE STALE ONE
```

The seat's newer state is on disk and **invisible to `resolve`**. Same consequence as Rachel's
`adopt`-regresses-the-pointer-backward finding, by a different mechanism: **fork vs regress, one
victim** — a seat detached from its own newest record.

⇒ **This is F-1's defect, at the argument layer instead of the constructor layer**: *persona
over-loaded into a path that means something else.* F-1 **destroys a record** through the pointer;
this **detaches a seat** from its record through the pointer. **Same overload, two victims.** A
reader who treats them as separate will fix one and leave the other.

### Does closing F-1 close half of this? — MEASURED: NO

Mr. Radio's open question (12:44). Answer is negative, and structurally so:

```
is_record_path("io/mementos/arnold-reviewer.md")  → False   ← guard is BLIND
is_record_path("io/mementos/arnold-20260721.md")  → True    ← guard sees this one
```

An F-1 constructor guard keyed on *"the pointer path is record-shaped"* **cannot see the fork**,
because `arnold-reviewer.md` is not record-shaped. **No part of this row closes for free.**

### Recommendation (approved, not built)

A **`--label` that does not participate in identity**: record `<persona>-<label>-<sid8>.md`,
pointer stays `<persona>.md`, record still stamped + mirrored + pointed. Converts ~72% of the
bypass traffic onto the sanctioned path without inventing an artifact class.

**Where the missing-verb hypothesis survives, narrowly**: the 200 keep being written, nothing has
ever refused them, and **F5 governs them correctly precisely because it is location-based rather
than naming-based** — the strongest argument for the broad predicate, stronger than the "10% of
its surface" one it was actually approved on.
