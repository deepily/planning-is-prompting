# Built ≠ Landed — seven instances in one evening, and the verification ladder they imply

**Date**: 2026.09.07 · **Author**: María 🌸
**Status**: 🔴 FINDINGS + PROPOSAL. Nothing in `workflow/` has been edited. Rick reviews before graduation — his standing rule, row `155f26e3`.

---

## 0. Why this is written down

One evening, one fleet, **seven separate instances of work that was real and unreachable.** Each wore a different costume, and in each case a competent session was one step from reporting success.

That is not seven accidents. It is one defect class with seven surfaces, and the remedy is a **ladder** — because each rung catches a failure the rung below it cannot see.

---

## 1. The seven

| # | What was claimed | What was true | How it was caught |
|---|---|---|---|
| 1 | "The date filter is **landed**" | 10 modified files, **zero commits** | `git log` — HEAD unchanged |
| 2 | A row **closed green**: `title` + `to_status` shipped | Neither existed in the tree | read the serializer at the cited sha |
| 3 | Design DONE, API door DONE, door's proof DONE | **No accordion rendered.** Three correct closes, zero feature | the operator noticed nothing had appeared |
| 4 | "The TITLE column is broken" | Both sides of the code were **correct** — the running process predated its own serializer | probed the live endpoint, not the file |
| 5 | "The change is served correctly" | **The operator's browser would still have shown the old page** | a cache-token bump, by a worker who thought past the standard |
| 6 | The parity-oracle suite guards the accordions | **Four test files reachable by no runner** — they run for nobody | a gate-reachability census |
| 7 | A branch was ready to merge | **20 of its 22 commits belonged to another session** | checked before merging, cherry-picked instead |

---

## 2. The ladder

Each rung is invisible from the one below. **A session that stops early cannot tell that it stopped early** — that is what makes this class expensive.

| rung | question | catches |
|---|---|---|
| 1 | Does it compile / pass? | syntax, logic |
| 2 | **Is it committed?** | #1 |
| 3 | **Is it merged into the branch that deploys?** | #2, #7 |
| 4 | **Is the running process serving that code?** | #4 — *a saved file is not a served file* |
| 5 | **Will the user's browser show it?** | #5 — *a served file is not a rendered file* |
| 6 | **Does the feature exist, or only its prerequisites?** | #3 — the expensive one |
| 7 | **Does anything actually invoke the guard?** | #6 |

**Rung 6 is the one no individual row can enforce**, because every contributing row closed correctly and none of them was wrong. It requires someone asking *"can the user see it?"* of the whole chain rather than of any link.

---

## 3. Three instruments that made the difference

All three came from workers, unprompted, and all three generalize well past this defect class.

### 3.1 The positive control

> *"An absence is worth nothing until the instrument has returned a presence."*

A census reported two priority values appearing once each. Before trusting that, the worker proved the search **reached**: the other four values returned 58, 59, 54 and 22 hits.

**Why it matters**: an hour earlier another session's search returned **zero hits** because its pattern used an alternation the tool didn't honor. It was one step from filing *"the comparator exists and nothing calls it"* — about code with **four live call sites**. The instrument was wrong, not the tree, **and an empty result looks identical either way.**

### 3.2 The discriminating probe

> *"A door that refused everybody would have passed both probes identically."*

Two refusals were proven against a live guard. The worker refused to call it verified without a **success** case — otherwise *"it refuses bad input"* and *"it is welded shut"* are the same observation.

**Corollary, found the same night**: when the toggle under test is *already* in the expected state, a test reading the live system passes whether or not the code changed. It is measuring someone else's keypress.

### 3.3 The refusal to forge

A worker could have turned his own test green in one keystroke by typing a manager's name into a caller-declared field. He declined — it would have written a false identity into an **append-only** ledger, which can never be corrected afterward, only annotated.

He did not argue the field was weak. **He refused to exploit it and let the gap speak for itself.**

## 4. Two more rules the evening earned

**A line number is a coordinate, not a reference.** Three times a cited `file:line` had moved between the reading and the acting — twice within two minutes, once by ten lines after an unrelated commit. **Both readings were correct when taken.** Pair every citation with a sha and a wall-clock moment; name registration sites by content.

**A finding with no owner reads as closed.** Two real reds sat on the main line belonging to nobody; left in a DM they would have evaporated. Likewise, **an assignment delivered only by DM is invisible to the work-owed oracle** — a worker corrected me on that, and was right.

---

## 5. One finding that has no fix here

The override file behind an admin endpoint was reported as world-writable. It is not — **every seat on this box runs as the same UID.**

⇒ *"Any worker can write it"* is true, but not because permissions are loose: **there is no identity boundary between seats at the OS level at all.** That is worse than a permissions bug and **unfixable by `chmod` or `chown`** — you cannot separate what is one user.

⇒ All protection must therefore live **above** the filesystem. Worth stating plainly rather than dropping, or the next reader will assume that layer is guarded.
