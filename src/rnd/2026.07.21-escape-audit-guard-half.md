## 3. The one green-by-construction claim, written so a skeptic can fire it

`SLOT_DENIAL` escape 2 is `memento_io.py write`. Its target comes from `git rev-parse --show-toplevel`, **not** from cwd. F5's entire failure mode is a RELATIVE path resolving against the caller's cwd. A path derived from the toplevel cannot be non-canonical relative to that same toplevel, so F5 has nothing to fire on. Empirically, every `write` in this sweep (a dozen, from repo root and from sandboxes) landed at `io/mementos/` or `.claude-memento*` directly under the toplevel, verified by the RECORD/MIRROR/POINTER banner.

**The adversarial variant, not spent — fire this to refute:**

```bash
# a sandbox repo containing a SIBLING io/mementos/ that F5 would otherwise match
mkdir -p "$W/repo/sub/io/mementos" && cd "$W/repo/sub"

# claim: the record lands at $W/repo/io/mementos/ (toplevel), NOT $W/repo/sub/io/mementos/
```

## 5. What the auditor got wrong, and how it was caught

An audit's error rate is evidence about its verdicts. Three, all self-caught, none caught by review:

1. **`${PIPESTATUS[0]}` read `echo`, not `python`** — reported `exit=0` for the own-persona `--allow-foreign-record` form. A bogus 0 there reads as *"both forms work"* — the flattering answer, arriving free. Re-measured with `--content-file` and no pipeline: **1 and 0**.
2. **A line-scoped grep asked about a multi-line command** — reported three corpus prescriptions as missing `--slot`; they are `\`-continuation blocks with the flag on line 2. **The false direction was the one that flatters the audit**: a sweep that had just ruled `--slot` required would have "discovered" it broke three prescriptions.
3. **Claimed `ensure_gitignored` writes `.gitignore` unconditionally** — it does not: gated on `is_ignored()`, appends only what is missing, announces the repair, and Rick ruled the trade in the docstring. **Withdrawn; no row filed.** The manager had already echoed the claim back, which is how one unverified statement acquires a second source.

Also recorded: the **first** positive control failed to reproduce, and the fault was the auditor's — both writes used the same persona, so no pointer/record collision was reachable **under any outcome**. "Victim intact" measured nothing. The reproduction needs a **record-shaped persona slug**.
