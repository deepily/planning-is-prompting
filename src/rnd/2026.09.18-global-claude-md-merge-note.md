## Judgment calls

1. **The "debris" is not leaked debris; I excluded it anyway, as briefed.** `## Session: 5c8a3081`, `### Touched Files`, `## Pending` and `## Completed (Recent)` sit **inside fenced code blocks** in the copy (lines 155–173 and 218–228). They are the worked format examples for the manifest and for TODO.md, not a session manifest that leaked in. A heading grep that ignores fences reads them as stray headings. I followed the brief and left both out, and the outcome holds on its own grounds: the TODO example contradicts live's current definition of TODO.md (Decisions Log + Pending-Decisions queue + backlog, not a Pending/Completed checklist), and live points to `workflow/session-start.md` Step 3.5 for the manifest format, which does carry it (lines 522–662). **If María wants the manifest example back, it is 19 lines, and it still matches the v2.0 format.**
2. **Priority mandate: restored without "Not enforced in code."** The copy said the P0–P5 rule was unenforced. At 2026-09-18 ~21:10 EDT the store refused this row's own creation at P1 with HTTP 403: *"Creating a ticket at P1 requires the operator or a manager; a worker files P5."* Restoring a sentence I had just watched turn false would put a known-wrong claim into the file, so I cut that clause and kept the rest verbatim.
3. **The end-of-file recap ("BEFORE YOU REPLY — THE THREE ACRONYMS") is not restored.** Live moved that table to the top of the file and expanded it; every row in the recap is a shorter form of a live row, and its palette line is live's glyph paragraph. Restoring it would repeat the mandate twice in one file, which rule 5 forbids. The one argument for it — a reminder at the end, where the model reads last — is a design choice Rick made when he moved it, so live wins.
4. **Where live replaced a table or list with a line, I added only what the line lost — sometimes as a table.** The BANNED habits: live keeps them as one line; the copy's table carried an "Instead" column the line dropped. I restored the table, which repeats the left column, because the "Instead" answers cannot be read without their habit next to them. Likewise the manager-autonomy "Rule" column comes back as a per-tier list under live's two-column table, since a live table row cannot gain a cell without editing a live line.
5. **Caps and names were kept as the copy wrote them.** Both versions carry the NoYell rule and both use caps for emphasis, so restyling restored text is a separate change nobody asked for. The `git stash` receipt restores the persona names (john, Tiffany) that live replaced with "one seat" / "a peer"; live names Pocholo in the section directly above it, so anonymizing was not a file-wide policy.
