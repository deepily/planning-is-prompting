## 6. Lessons for the failure-mode catalog (candidates, not rules)

- **Folding a sentence into its neighbour changes its scope.** Trigger: a pruning rewrite that merges two sentences to save a line. Symptom: the commit message says "no instruction changed" and the merged sentence now applies to something wider or narrower. Guard that caught it: a reviewer reading each hunk against the lines around it, never the commit message. One sighting, three instances in one batch.
- **A line count that ignores markup.** Trigger: counting only content lines when a cut removes a whole table or section. Symptom: author and reviewer totals differ by the header, separator and heading lines. Guard: say in the shortlist that an emptied heading or table goes too, and count it. Two sightings in one day (batches two and three).
- **A checker rooted somewhere other than where you are standing.** `pip_drift_check.py` compares against `$PLANNING_IS_PROMPTING_ROOT`, the main checkout. Run in a worktree it reported `version_lies` on a correct tree (my run), and run from `workflow/scripts` it reported "nothing installed", a false green (Chloé's memento). Guard: set the variable to the worktree; better, have the tool refuse when its root and the current tree differ.
- **Harvest after reap, again.** Of the four retros in this version's corpus, three are written from reap mementos (sessions 213 and 215, and this one). Trigger: a reap taken for a good reason (a peer's P0, an offline user) by a manager who is also the steward. What saved the testimony was element 9 of the memento, which `dismiss_sessions` enforces. What was lost is the cross-examination, which nothing enforces. This is the section 3.3 point again: the free mechanism was skipped by the person who wrote it down.
- **An ask fired at someone who is not there.** A blocking ask returns its default when the user is offline, and the default reads like an answer unless the prefix is checked. Guard used from the third card on: send one plain notify first and read its result.
