## 6. Lessons for the failure-mode catalog

- **Deposit mistaken for harvest: second sighting in two days, same manager, after writing the guard down.** Trigger: a seat replies "deposited" and a reap is one call away. Symptom: the Steward never acks, and drafted rules can only be tested against files. My drafted guard, that `dismiss_sessions` refuse to reap while a live Steward has not acked, was **refuted in cross-examination** (addendum). The guard that stands is Cheech's: the "deposited" reply lists every uncommitted file the seat holds, and the reap waits until each path exists.
- **Card framed from the document, not from the system.** Trigger: building decision options from a plan's wording. Symptom: the owner has to write in an option that already ships, or correct a premise. Guard: before a decision card, check each option's premise against the running product or the owner's last ruling, and keep the "Other" option. First sighting, two instances in one walkthrough.
