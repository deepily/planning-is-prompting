## 6. Lessons for the failure-mode catalog (if any)

- **Fix-shifted defect.** Trigger: a fix is applied to one clause. Symptom: the sentence next to it now contradicts the plan, or the fix's own new text has a gap. Guard: G2.
- **Relay narrowing.** Trigger: a ruling or verdict crosses a session boundary as prose. Symptom: a narrower ruling in the plan, or a verdict without its token. Guard: G1.
- **Name-keyed independence.** Trigger: a fresh-cast rule written as a list of names. Symptom: the pool runs out, an excluded name returns from a wildcard spawn, and authors are not covered. Guard: G3.
